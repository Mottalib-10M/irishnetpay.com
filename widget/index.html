Embed Our Calculator on Your Site

Add the IrishNetPay.com Irish salary calculator to your website, blog, or intranet. The widget is free to use, responsive, and always up to date with the latest Irish tax rates.

Embed Code

Copy and paste the following HTML code into your website where you want the calculator to appear:

<iframe src="https://irishnetpay.com/embed/" width="100%" height="700" frameborder="0" style="border:none;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.1);" title="Irish Take-Home Pay Calculator"></iframe>

Installation Instructions

  1. Copy the embed code from the code block above.
  2. Open your website editor and navigate to the page where you want to display the calculator. Switch to the HTML or code view if you are using a visual editor.
  3. Paste it into the page, inside the column where the calculator should sit: the frame takes the full width of that column on a phone as on a desktop.
  4. Save and publish your page. The calculator will load directly from IrishNetPay.com and will always reflect the latest tax rates and features.

Customization Options

Three attributes of the iframe tag decide how the Irish salary calculator sits in your page:

Attribute Default Description
width 100% Keep 100% so the frame follows the column on mobile; a fixed value in pixels suits a sidebar.
height 700 The height of the calculator in pixels. Increase this value if content is cut off, or decrease it for a more compact display.
style border:none; ... Inline CSS for additional styling. You can modify the border-radius, box-shadow, or add a border to match your site theme.

Terms of Use

Any site may embed it, commercial or not, at no cost. The credit link under the frame stays visible, and the figures inside the frame are not altered. Because the frame loads from irishnetpay.com, Budget changes to Irish tax bands, credits, USC and PRSI reach your readers the day we publish them, and the layout may change over time.
